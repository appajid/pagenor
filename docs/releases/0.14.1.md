# Pagenor 0.14.1 — desktop development preview

This release brings the local editor and publishing milestones since the 0.7.0
preview to macOS, Windows and Linux. It preserves Pagenor branding, native/scoped
font discovery, inline Unicode Indic input, separate document icons and `.pgnr`
documents.

## Changes

- Editor: richer Properties and Effects controls, page/master navigation and
  sizing, safe master deletion, style previews, Keep Options, improved Find/Change,
  nested-group selection and editing, and per-placement image relinking.
- Publishing: retained empty-frame fitting, Keep with Previous, more reliable
  reflow and footnotes/tables, book TOCs and covers, queued image placement and
  improved overprint/overset diagnostics.
- Text and interchange: shaping across paint/feature changes, complex-script
  selection, IDML compatibility fixes and bounded native/archive/SVG/text imports.
- Reliability: asynchronous native file dialogs and link checks, bounded font
  instance/preview handling, recovered dangling frame references and compact saves.
- 0.14.1 correction: refuse QR merge bindings to standalone generated QR paths,
  which would retain an old visible code. Both field-binding commands are guarded;
  valid frames still receive a different vector code for each record.
- Packaging: version-matched release notes are required before publication, and
  the Mac GUI app now carries its own software, provenance and owner-brand notices.

Native capability **8** reads older documents, including legacy `.pagenor` files.
Older app versions can reject new saves rather than silently discard new settings;
keep older copies when sharing with an older Pagenor installation.

## Downloads

- macOS: universal Intel/Apple-silicon DMG and companion CLI ZIP.
- Windows: x64, x86 and ARM64 MSI installers and portable ZIPs.
- Linux: x86_64 and ARM64 AppImage, Debian, RPM, tar and Flatpak bundles.
  Archive/AppImage packages target glibc 2.35 or newer.
- Match every download against its supplied SHA-256 manifest.

These remain development previews. Windows packages are unsigned; Mac packages
are ad-hoc signed and not notarized, so macOS may require an explicit security
exception on another Mac. Interactive Windows/Linux editor and physical-printer
validation are separate from the automated native checks. INDD recovery remains
experimental; PageMaker 6.5/7 recovery uses the optional helper described in the
[import notes](https://github.com/appajid/pagenor/blob/v0.14.1/docs/pagenor/PAGEMAKER_IMPORT.md).
Legacy-font conversion needs a verified mapping for the actual font encoding;
this release does not promise automatic Anu 6/7-to-Unicode conversion.

## Validation and provenance

The source baseline passes all seven local Mac gates: **3,163 tests**, zero
failures, seven existing skips and twenty WASM packages. Six core libraries also
compile-check for Windows GNU and Linux GNU. The desktop workflow gates publication
on native Windows/Linux quality, package checks, all three Windows MSI
install/architecture/association/icon/export/uninstall checks, and both Linux
Flatpak builds/execution checks. Finished Mac DMG/install-copy signatures,
universal architectures, versions, icons and CLI PDF exports are verified before
Mac assets are appended to the same release.

[Change log](https://github.com/appajid/pagenor/blob/v0.14.1/CHANGELOG.md)
and the linked adoption ledgers identify source pins and compatibility decisions.
Pagenor branding rights belong to Appaji Ambarisha; software retains MIT OR
Apache-2.0 and all applicable upstream, asset and font attribution. No owner-supplied
private fonts or user documents are included. Prior published releases stay intact.
Source review and default-branch integration remain separate from the tagged
release branch, following earlier desktop previews.
