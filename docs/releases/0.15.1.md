# Pagenor 0.15.1 — Windows PageMaker text repair

Windows development preview, 21 November 2026. This patch provides updated x64,
x86 and ARM64 MSI installers and portable ZIPs. Previous release files remain unchanged.

## PageMaker import

Fix Windows CRLF decoding that displayed internal `@PAGENOR-BYTES-V2@` transport
markers instead of the original text, affecting both English and legacy Telugu.
The bundled byte-preserving PageMaker converter is included in every MSI and ZIP,
together with its corresponding source and licence notices.

Conversion reads P65/PM7 directly. It preserves original legacy character-code
meaning and font assignments; install the original fonts to render legacy text.
It does not require a PDF, reconstruct content from a PDF, translate the text or
automatically convert Anu text to Unicode. PageMaker layout import remains experimental.
Reopen the original PageMaker file with this version: previously saved conversions
containing transport markers are not automatically rewritten.

The installer retains its success/Finish screen, desktop and Start menu shortcuts,
file associations and upgrade identity. Save documents and close Pagenor on Windows,
then run the matching MSI to update; do not uninstall the old version first.
The portable ZIP is an alternative without installation; extract the whole folder.

## Other retained changes

All 0.15.0 changes and earlier 0.14.2 installer, bundled PageMaker and performance
improvements remain. PDF exports, including single-page exports, now display page
progress and finishing/saving states. Successful export closes the progress window
and reports PDF export completed. Errors remain visible and cancellation is safe
before saving.
