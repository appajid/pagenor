# Pagenor 0.15.1 — desktop publishing preview

Windows packages were published on 21 November 2026; Mac and Linux packages were
added on 22 November 2026 from the same tested source. The existing Windows
installers and portable ZIPs are unchanged.

## Downloads

- Mac: universal DMG for Apple Silicon and Intel, plus a universal CLI ZIP.
- Windows: x64, x86 and ARM64 MSI installers and portable ZIPs.
- Linux: x86_64 and ARM64 AppImage, DEB, RPM, tar.gz and Flatpak packages;
  each AppImage has matching zsync update data.
- `SHA256SUMS.txt` covers all twenty package payloads.

## PageMaker import

Fix Windows CRLF decoding that displayed internal `@PAGENOR-BYTES-V2@` transport
markers instead of original text, affecting both English and legacy Telugu.
The byte-preserving converter, corresponding source and licence notices ship in
all Windows packages and both Mac packages. Linux still requires an external
PageMaker helper; the Linux packages do not bundle it.

Conversion reads P65/PM7 directly. It preserves original legacy character-code
meaning and font assignments; install the original fonts to render legacy text.
It does not require a PDF, reconstruct content from a PDF, translate the text or
automatically convert Anu text to Unicode. PageMaker layout import remains experimental.
Reopen the original PageMaker file with this version: previously saved conversions
containing transport markers are not automatically rewritten.

## Retained features

All 0.15.0 changes and earlier 0.14.2 installer, PageMaker and performance
improvements remain. PDF exports, including single-page exports, display page
progress and finishing/saving states. Successful export closes the progress
window and reports PDF export completed. Errors remain visible and cancellation
is safe before saving.

The Windows installer retains its success/Finish screen, desktop and Start menu
shortcuts, file associations and upgrade identity. Save documents and close
Pagenor on Windows, then run the matching MSI to update; do not uninstall the old
version first. Extract the whole portable ZIP if using the alternative build.

## Limits

This remains a development preview: Windows packages are unsigned and Mac packages
are ad-hoc signed without notarization. Native Linux formats retain their Ubuntu 22.04
build baseline (glibc 2.35+); Flatpak uses its declared freedesktop runtime. Interactive Windows/Linux editor validation, the
reported Windows 10 responsiveness retest, physical-printer testing and complete
PageMaker layout fidelity remain separate work. Earlier release binaries are
unchanged; the shared 0.15.1 checksum manifest is extended for the added platforms.
