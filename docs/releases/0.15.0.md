# Pagenor 0.15.0 — local upstream adaptation milestone

Status: local development source; all seven quality gates pass. No release is published
and no installed application is replaced by this task.

Thirty upstream source scopes improve editing, footnote search, table borders,
IDML style references, dialog controls, safe font/image handling, GPU limits and
command-line behavior. Indic pattern breaking is available for Telugu, Hindi,
Marathi, Bengali, Assamese, Gujarati, Punjabi, Odia, Tamil, Kannada and Malayalam.
Set the text's language in Character options; ordinary English text keeps its
existing hyphenation rules. Indic syllable breaks do not add visible hyphens.

Native Edit > Paste can embed clipboard bitmaps or copied image files. An ordinary
text caret inserts one inline object; an empty selected frame receives the image,
otherwise a new frame is placed on the current page. This is one undo step and
embedded bytes survive native save/reopen. Stored image resolution determines
physical size, capped to 60% of page width and height. Reads are bounded, run off
the interface thread and are discarded if their target context changes.

Bitmap-only Ctrl/Cmd+V awaits a separate adaptation to the pinned frontend; use
Edit > Paste for bitmaps. Inline image insertion into tables or footnotes reports
unsupported without modifying their text. This release does not claim a full
Windows/Linux native runtime test or the affected Windows 10 user's performance
retest. The previously verified 0.14.2 Windows update candidates remain unchanged.

The source review, authors, immutable heads, regression results and remaining
queue are in [the adoption ledger](../upstream-adoption-20261120.md). Native
format capability remains 8. Pagenor branding and owner asset rights are retained.
