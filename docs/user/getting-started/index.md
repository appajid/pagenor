[Install Pagenor](install.md), then open it. On the Welcome screen, choose a
new-document preset, open an existing document, or select a recent-document thumbnail.
You can also open the sample magazine to explore a finished layout.

The editor's tools and panels appear after a document opens. Closing the last document
returns to Welcome. **File → Open Recent** lists recent documents too.

Start with [Create a new document](../guides/create-a-document.md),
[Open a file](../guides/open-a-file.md), or [Place images and text](../guides/place-images-and-text.md).
Save editable work as `.pgnr` and [export a PDF](../guides/export-a-pdf.md) for sharing.
