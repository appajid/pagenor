---
title: Which systems does Pagenor run on?
description: Desktop packages for macOS, Windows and Linux.
order: 20
verified: 0.7.0
---

This milestone ships desktop packages for:

- **macOS:** a universal Apple silicon and Intel bundle.
- **Windows:** x64, arm64 and x86 MSI installers and portable ZIPs.
- **Linux:** x86_64 and aarch64 AppImage, Flatpak, DEB, RPM and tar.gz packages.

The Rust workspace also retains its checked WASM build path. A browser package,
FreeBSD and RISC-V packages are not part of this Pagenor desktop milestone.
See [Install Pagenor](../getting-started/install.md) and the requirements on the
[Pagenor release](https://github.com/appajid/pagenor/releases) you download.
