Pagenor is a page layout and publishing app. It is an open-source alternative to Adobe InDesign, maintained by Appaji Ambarisha as an independent fork with upstream contributor credits. If you know InDesign's tools, menus and panels, you will find them here.

It has spreads and parent pages, text frames that thread from one to the next, paragraph and character styles, swatches and text wrap. It opens and saves InDesign Markup (IDML) files and exports PDF, PNG and EPUB. The editor is free and open source; branding assets have separate terms. The project is in pre-alpha, so expect gaps.
