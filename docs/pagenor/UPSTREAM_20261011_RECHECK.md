Implementation still requires pinned-source review, focused regressions, full local gates and native inspection as applicable.

- #514: crates/mcp/src/backend.rs already never resends failed requests and checks framing/authentication/reply IDs. Existing P00.5 work is stronger than the new upstream minimal patch.
- #464: crates/fonts/src/fontdb.rs already honors absolute XDG_DATA_HOME and XDG_DATA_DIRS; catalogue deduplication remains.

- #506: recovery key reservation avoids overwrites, but per-process locks are absent. A second process can still see a live process's recovery entries; isolate without weakening existing ownership.
- #501/#468: local master settings/guides are implemented. Source IDML only marks inheritance through the Pagenor extension; source-override inference and dialog/unit deltas are useful.
- #498: endnotes/editorial payload copying is present, but direct marker-count slicing remains. Adopt malformed-input safety without dropping the working feature.
- #510: local parse_color still chooses scale independently per component and also supports Gray; retain that extra mode.
- #504: existing native UI font fallback only covers three CJK sample characters. Document canvas fallback and keyboard composition are separate systems; this UI fix complements them.
- #474: local single-sided master choice still takes the last page. Preserve geometric left/right selection for RTL.

Earlier pending audit items (#230 decoration fidelity, #153 remaining temp/recovery protections, #300 PDF conversion caching) are not cancelled by this review.
